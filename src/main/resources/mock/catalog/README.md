# Mock-файлы каталога

Здесь лежат сохранённые ответы внешнего каталога.  
Их задача — зафиксировать форму контракта и дать стабильные данные для mock-режима.

Важно:
- JSON-файлы хранятся без комментариев и без хвостовых запятых;
- имена файлов не меняются, чтобы сценарии можно было однозначно сопоставить с ответами.

| scenario | file | expected status |
|---|---|---|
| search-success | search-success.json | 200 |
| search-empty | search-empty.json | 200 |
| details-success | details-success.json | 200 |
